Implementation began on 2026-10-19 following the owner's explicit apply request. This authorizes the reviewed frontend plan and adoption of ADR-0004, with no OAuth/backend work or Slice 002.

## Implementation results

German is now the deterministic default/fallback, including English-browser visits and direct workspace links. The accessible native Deutsch/English control saves only an explicit supported language choice. Unsupported/unreadable storage falls back to German; denied writes retain in-memory switching. Language changes update document language, title, description, screen text and announcements without navigation or learning-state reset.

### Modules and contracts

- `src/app/i18n.ts` and `main.tsx`: one awaited initialization using bundled resources, supported-language allowlist, safe preference access and development missing-key diagnostics. App owns the selector; features do not import composition.
- App/NotFound, mission Catalog/Workspace, protocol-flow ActorCanvas/InteractionPaths/Timeline/Inspector: visible/accessibility copy resolves through namespaces. Existing route focus behavior, selection identity, mission-only route key, map scale/scrolling and text alternative remain.
- Six UTF-8 resources under `src/locales/{de,en}/{common,mission,protocol-flow}.json`: current screen copy, educational explanations, accessible names, action feedback and plural/interpolated counts. Technical documentation stays English.
- Canonical mission/protocol-flow contracts and the two existing mission data modules: language-neutral content-key references and stable availability/evidence codes replace English presentation values. Mission/actor/group/checkpoint/event IDs, event endpoints, explanation order and registration remain unchanged.
- `EvidenceField.value` distinguishes technical literals from translated educational annotations. The existing allowlisted OAuth projection retains `code`, `S256`, `BFF` and `Access Token`; synthetic-data/channel descriptions are translated. Internal events enforce `not-observable`; no HTTP edge/observer/time/outcome is invented.
- `useMissionWorkspace`: one small notification-intent union (`loaded`, `replayed`, `reset`, `fitted`), replacing stored sentences. The protocol-selection hook remains localization-independent. No parallel localized event store, new shared layer, repository, plugin or controller was introduced.
- Styling changes are limited to the native select's inherited font/focus/treatment and header wrapping needed for narrow viewports. Existing colors, typography sizes, surfaces, geometry, artwork and animations remain.
- ADR-0004 is Accepted; proposal is APPROVED for this scope. AGENTS, package guide, product language guidance and the two UX documents are aligned. Prior verification reports and other changes remain intact.

Dependencies added: `i18next` **26.5.2**, `react-i18next` **17.1.0**, with their required transitive packages. No detector, HTTP resource loader or backend dependency. Installation used Node's system CA support after the initial registry certificate-chain error; TLS verification stayed enabled. npm audit reported zero vulnerabilities at installation.

The production JS bundle grows from 294.09 kB / 92.83 kB gzip to 375.24 kB / 116.92 kB gzip, reflecting the two libraries and both bundled languages. No asynchronous translation loading state is needed for this small initial resource set.
