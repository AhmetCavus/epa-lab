## Boundaries and operational follow-ups

- These results do not deploy the new UI or attest a new public release. Existing public SPA,
  BFF, Keycloak, HAPI, PostgreSQL and routing remain outside this change's mutation scope.
- The real harness uses disposable Keycloak 26.8.2 `start-dev`/tmpfs and a private test CA;
  its historical `providerProductionGate` wording describes this test harness, not a change
  to the already deployed production-mode provider. No original provider/database volume is mounted.
- Privileged UFW rule ordering/duplicates/default policies/backup integrity remain the earlier
  explicit operational follow-up in [change 001 verification](../001-oidc-pkce/verification-report.md).
  This frontend change performs no firewall or administrator action.
- Closing protected-state comparison and any unrelated external container drift are recorded
  separately in implementation verification; no unrelated service is repaired or rolled back.
